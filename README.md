LoArt — Interactive Digital Art Gallery

LoArt is a modern interactive digital art gallery created to showcase personal artwork through an immersive and cinematic web experience.
The project combines elegant visual design, smooth animations, and a responsive mobile-first architecture to create a virtual exhibition space inspired by contemporary museums and artistic storytelling experiences.

✨ Features
🎨 Interactive artwork gallery
📱 Mobile-first responsive design
🌍 Spanish / English language switcher
🖼️ Fullscreen artwork viewer
↔️ Swipe & drag gallery navigation
⚡ Smooth transitions and motion effects
🌌 Cinematic hero section
🧭 Dynamic artwork detail pages
📖 Expandable artwork descriptions
🖤 Premium minimalist aesthetic
🚀 Optimized image loading for production
🎭 Framer Motion animations

🎨 About the Project

LoArt was developed as a personal digital exhibition space focused on presenting artwork in a more immersive and emotional way than a traditional portfolio.

The visual direction was inspired by:

modern museum interfaces
cinematic web experiences
minimalist editorial layouts
interactive storytelling galleries
📸 Gallery Content

The artworks featured in this project are original paintings and personal artistic works created across different thematic collections and artistic periods.

Themes include:

floral studies
landscapes inspired by Valdivia
seasonal collections
emotional and atmospheric compositions
